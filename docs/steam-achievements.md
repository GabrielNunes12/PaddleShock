# Steam achievements setup

The game unlocks achievements through `SteamManager.unlockAchievements` using the API names
below. **Steam only accepts names that exist in the app's Steamworks config**, so before
release create each one in Steamworks: *App Admin > Stats & Achievements > Achievements*,
then publish the config. Until then (and with the dev App ID 480) the calls fail quietly and
achievements still track locally.

Icons (256x256 JPG, unlocked + locked) are in `branding/achievements/`, generated by
`tools/AchievementIconGen.java` (`./gradlew classes && java -cp build/classes/java/main tools/AchievementIconGen.java`).

Unlocks are stored in the local profile too and re-sent to Steam on every launch, so anything
earned offline, or before the Steamworks config existed, reaches Steam the next time the game
runs with Steam available.

Portuguese (Brazil) display names/descriptions are in `strings_pt_BR.properties`
(`ach.*` keys) - add them as the *Portuguese - Brazil* localization in Steamworks.

To add an achievement: add it to the `Achievement` enum, give it a rule in
`AchievementTracker`, add `ach.<name>.title/.desc` strings in both languages (a test enforces
this), add a badge label in `AchievementIconGen`, regenerate the icons, update this table, and
create it in Steamworks.
